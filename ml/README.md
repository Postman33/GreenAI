# Обучение и проверка моделей инженерных сетей

Установка зависимостей через локальный Poetry:

```powershell
.\.tools\poetry\Scripts\poetry.exe install
```

Структура данных:

```text
ml/
  train.py
  validate.py
  train/gas/*.dxf
  train/water/*.dxf
  train/heat/*.dxf
  train/power/*.dxf
  validate/gas/*.dxf
  validate/water/*.dxf
  validate/heat/*.dxf
  validate/power/*.dxf
```

В обучающих и проверочных DXF цветом ACI 3 отмечается геометрия настоящей
трассы соответствующей сети. Остальные примитивы её слоёв считаются
отрицательными примерами. Один DXF нельзя одновременно класть в обучающую и
проверочную выборку одной сети.

Первый файл для разметки газопровода находится в
`ml/train/gas/Камчатская_gas_train.dxf`. Зелёным ACI 3 нужно отметить только
линии трассы газопровода. Выноски, стрелки, подписи и поперечные условные знаки
оставляются исходного цвета.

Первый файл для разметки теплосети находится в
`ml/train/heat/3-я_Парковая_heat_train.dxf`. Рабочий слой —
`Сущ_сети_Теплосеть` (также поддерживается хвост `Теплосеть`). Зелёным ACI 3
нужно отметить только продольные линии реальной трассы. Поперечные штрихи,
выноски, стрелки, подписи и другие условные обозначения остаются исходного
цвета. Цвет нужно задавать самим выбранным примитивам, не всему слою.

Вторая размеченная улица теплосети находится в
`ml/train/heat/Нижние_Поля_heat_train.dxf`. До включения в обучение она была
проверена как независимая выборка: отчёт сохранён в
`output/ml_validation/heat/20260917_153332/validation_report.json`. Для
последующей независимой оценки нужен новый DXF, которого нет в `ml/train/heat`.

Первый файл для разметки силового кабеля находится в
`ml/train/power/Курганская_power_cable_train.dxf`. Рабочий слой —
`Кабель электрический` (также поддерживается хвост
`Сущ_сети_Кабель электрический`). Зелёным ACI 3 отмечаются только линии,
которые идут вдоль настоящей трассы кабеля. Поперечные штрихи, стрелки,
выноски, подписи и компактные условные обозначения не размечаются.

Обучение:

```powershell
.\.tools\poetry\Scripts\poetry.exe run python .\ml\train.py
```

По умолчанию скрипт обучает воду, газ, теплосеть и силовой кабель и сразу сохраняет
промышленный bundle:

```text
models/utility_detector/latest/
  gas_pipe.onnx
  water_pipe.onnx
  heat_pipe.onnx
  power_cable.onnx
  metadata.json
  training_report.json
```

Независимая проверка:

```powershell
.\.tools\poetry\Scripts\poetry.exe run python .\ml\validate.py
```

Проверка газопровода:

```powershell
.\.tools\poetry\Scripts\poetry.exe run python .\ml\validate.py --type gas_pipe
```

Проверка теплосети:

```powershell
.\.tools\poetry\Scripts\poetry.exe run python .\ml\validate.py --type heat_pipe
```

Отчёты и отладочные DXF сохраняются в
`output/ml_validation/<сеть>/<дата_и_время>`.

Отдельный этап конвертации не требуется: Joblib-файлы не создаются.
