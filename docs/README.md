# Документация Sylvitect-core

Sylvitect-core — вычислительное ядро платформы Sylvitect. Оно преобразует топографическую подоснову DXF в проверяемый план озеленения. Результат включает новый DXF, решения по каждой посадке, отчёты о применённых ограничениях и независимую проверку геометрии. Исходный чертёж не перезаписывается.

Техническая документация для передачи организаторам доступна в [PDF](../output/pdf/sylvitect-core.pdf). Исходник — [LaTeX](sylvitect-core.tex), сборка из корня репозитория: `./scripts/build_docs.ps1` (нужен Tectonic). [Краткая PDF-документация](../output/pdf/Sylvitect-core_documentation.pdf) собирается из [Markdown-источника](for_organizers.md) командой `python scripts/export_submission_pdf.py`.

Вычислительный интерфейс MVP — CLI. Веб-API и Swagger не предусмотрены; фотореалистичная визуализация не участвует в проверке нормативных отступов.
