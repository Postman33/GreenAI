## Перед записью демонстрации

1. Открыть итоговый DXF в nanoCAD и проверить читаемость подосновы и слоёв посадок. Сверить восстановленную дорогу с исходным чертежом: отчёт сохраняет `requires_visual_confirmation: true`.
2. Открыть презентацию в PowerPoint и проверить отображение шрифтов и переходов. Проверка структуры PPTX не заменяет просмотр в PowerPoint; рендерера приложения в среде проверки не было.
3. Прогнать сценарий с секундомером. Расчёт занимает около восьми минут; CAD и PDF подготовить заранее. Платную генерацию фотографий во время выступления выключить.
4. Для заявления о проверке на МосТех.ОС выполнить полный прогон на целевой сборке и открыть DXF в доступном CAD. Дополнительная проверка полного расчёта в Linux-контейнере Debian уже пройдена; установка, тесты и сверка с Windows описаны в [проверке платформ](platform_validation.md).

## Границы подтверждения

`passed` подтверждает реализованные проверки на извлечённой геометрии. Неполные сети, неверное распознавание слоёв или неточная реконструкция могут дать ошибку исходных данных. Для другой улицы нужен отдельный контроль геометрии. Фотореалистичные изображения служат иллюстрацией; измерять расстояния по ним нельзя.

Во время этой проверки платных запросов к OpenRouter не выполнялось. Изменения не добавлялись в индекс Git и не коммитились.
